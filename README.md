# MANDIBLE

버려진 살충제 공장에서 거대한 벌레들을 피해 탈출하는 1인칭 3D 공포 게임.
방역업체 직원이 되어 발전기 3개를 켜고, 약 4분 안에 하역장 셔터로 빠져나가야 한다.

Three.js로 웹에서 바로 돌아가며, 폰(가로 화면)과 PC 모두 지원한다.

### 조작

**PC**: WASD 이동 · 마우스 시점 · 좌클릭 손전등 · 우클릭(Q) 스프레이 · Shift 달리기 · Ctrl 웅크리기 · E 상호작용(발전기는 초록 칸에서 E) · M 지도 · J 수첩(벌레 기록) · F1 개발자 도구(개발·벌레 위치·밝게 버튼 표시/숨김, 표시 중엔 ` 개발자 모드, B 밝게 보기)

**폰**: 가로로 들고 플레이. 왼쪽 화면을 끌어 이동, 오른쪽 화면을 끌어 둘러보기. 바퀴가 몸에 붙거나 거미에게 잡히면 화면 아무 데나 연타. 할 일을 알려주는 대사엔 괄호로 누를 버튼이 붙음(폰에서는 줄바꿈되어 버튼에 가리지 않음).

**설정**(오른쪽 위 '설정', 시작 화면에서도 가능): 난이도, 시점 감도, 소리 크기, 밝기, 화질(낮음은 그림자 끔). 이 브라우저에 저장됨.

**난이도**: 쉬움(체력 5 · 스프레이 5 · 벌레가 느리고 발소리를 덜 들음 · 손전등이 천천히 뜨거워짐 · 시동줄 초록 칸이 넓음 · 잡혔을 때 버티기 쉬움) / 보통(체력 3 · 스프레이 3) / 어려움(체력 2 · 스프레이 2 · 지네와 거미가 더 빠름 · 발소리가 멀리 퍼짐 · 손전등이 빨리 뜨거워짐 · 초록 칸이 좁고 빠름). 체력과 스프레이 수는 새로 시작할 때 적용.

**지도**(M / 지도 버튼): 화면 구석 미니맵 대신, 2조가 공책에 볼펜으로 그린 약도를 손에 들고 봄. 보는 동안 걸음이 느려지고, 손전등이나 전등 불빛이 없으면 어두워서 잘 안 보임(어려울수록 더 어두움). 쉬움: 내 위치(빨간 점·방향), 발전기, 전등, 막힌 통로 표시 / 보통: 발전기·막힌 통로만, 내 위치는 지금 있는 방에 연필 빗금 / 어려움: 방 배치와 이름만, 켠 발전기에 X만 표시

**개발자 도구**: 개발·벌레 위치·밝게 버튼은 숨겨져 있음. PC는 F1, 폰은 '설정' 버튼을 1.5초 꾹 누르면 나타나고 다시 하면 숨음.

### 전체화면

- **PC · 안드로이드**: 오른쪽 위 '전체화면' 버튼 (PC는 F11도 가능). 폰은 게임 시작할 때 자동으로 전체화면 + 가로 고정을 시도한다.
- **아이폰**: Safari는 웹페이지 전체화면을 지원하지 않는다. Safari로 열고 **공유 → 홈 화면에 추가** 후, 홈 화면의 MANDIBLE 아이콘으로 실행하면 주소창 없이 전체화면으로 플레이된다.

## 지금 들어간 것

- 시작 화면: 노을 진 숲길을 끝없이 달리는 방역 트럭 안. 대시보드 무전기가 울리고(작업 지시서 클립보드와 마이크는 대시보드 앞면에 걸려 있음), 거기 달린 '무전 받기'를 누르면 본부 지시를 무전으로 받음(자막, 화면을 누르면 다음 줄). 페이드아웃 뒤 밤, 공장 마당에 세운 트럭에서 내려 하역장 셔터까지 걸어가고 셔터가 올라가면 안으로 들어가 게임 시작(들어가면 뒤에서 셔터가 내려옴). 건너뛰기 가능
- 맵: 하역장 → 창고 → 기계실 → 복도 → 생산 홀 → 실험실 → 비상 통로
  - 콘크리트 바닥, 페인트 블록벽(벗겨짐·물때·녹), 타일, 거푸집 콘크리트 질감
  - 랙과 찌그러진 박스, 팔레트, 드럼통, 포대, 배관·밸브, 철골, 형광등, 케이블, 체인
  - 지게차, 컨베이어, 탱크, 실험대와 유리기구·표본병, 표지판, 얼룩·웅덩이·균열, 거미줄, 빛 속 먼지
- 발전기 3개, 전등(안전지대), 쪽지, 출구 셔터
- 발전기 시동줄: 왔다갔다하는 표시가 초록 칸에 있을 때 E(폰은 손 버튼)로 당기기, 3번 맞히면 시동. 칸은 갈수록 좁아지고 빨라짐. 헛당기면 '펑' 하고 소리가 커서 주변 벌레가 몰려오고 한 번 성공한 게 날아감
- 무전: 발전기를 켤 때마다 본부 무전(남은 대수, 마지막엔 '당장 나와'). 가끔 지직거림 속에 이상한 목소리가 섞여 들어옴(최대 3번)
- 2조 이정훈의 녹음기 4개(창고·기계실·홀·실험실 테이블, 빨간 불 깜빡임): 재생하면 먼저 들어온 사람의 목소리 기록이 자막과 함께 나옴. 무전·녹음은 겹치지 않고 차례로 나옴
- 쪽지: 공책에서 찢은 구겨진 종이가 작업대 위에 놓여 있고, 읽으면 손글씨(볼펜, 줄 공책, 커피 자국, 지운 단어)로 보임
- 엔딩: 셔터 밖으로 나가면 밤 마당을 걸어 트럭에 다시 타고, 본부에 무전 → 지직거림 속 2조 목소리 → 마이크 위를 뭔가 기어 다니는 소리 → 암전 후 결과 화면 (화면/엔터로 다음 줄, 건너뛰기 가능)
- 2조 이정훈의 수첩: 새 벌레(바퀴, 유령거미, 늑대거미, 통로 막은 거미, 알집, 지네)를 처음 만나면 그 벌레를 조잡하게 그린 그림과 메모가 있는 수첩 한 장이 생김. 화면 왼쪽에 잠깐 떠오르고(게임은 안 멈춤), J 또는 수첩 버튼으로 펼쳐서 넘겨 볼 수 있음
- 지네에게 잡히면(약 2.6초): 얼굴 앞으로 솟구침 → 넘어지고 → 끌려가며 지네가 몸을 둘러 감음 → 떨어진 손전등 불빛 속에 머리가 위에서 천천히 내려옴(다리가 화면을 덮고 심장 소리) → 물림 → 사망
- 추격 음악: 거미나 지네에게 발견되는 순간 '쾅' 하는 경고음, 쫓기는 동안 북·저음·금속음 리듬이 깔리고 가까울수록 빨라지고 겹이 늘어남(현악 찌르기, 틱틱 소리). 놓치고 찾는 중엔 낮은 박동만 남고, 따돌리면 풀리는 소리. 숨어 있으면 작아짐
- 전등 체크포인트: 레버로 켠 전등이 저장 지점. 죽으면 그 전등 옆에서 체력 3으로 다시 일어나고, 전등이 10초 다시 켜짐. 진행(발전기·쪽지·리필·끊긴 실·알집·죽은 바퀴)은 유지, 스프레이는 남은 만큼, 벌레는 원래 자리로
- 바퀴 떼 4무리: 벽을 돌아서 길을 찾고, 지그재그·곡선으로 움직임. 빛에 닿으면 흩어져 물러나고(가끔은 날아서 도망). 쫓아오는 중이 아닐 때 5초 넘게 못 본 무리를 비추면 처음 1초는 도망가지 않아서 볼 수 있음, 빛으로 몇 초 막아내면 포기하고 둥지로 돌아감. 오래 쫓아오지 않음
- 스프레이 맞은 바퀴: 뒤집힌 채 바닥에 남아 계속 다리를 버둥거림
- 스프레이 맞은 거미: 배를 위로 하고 뒤집혀 다리를 위로 오므린 채 버둥거림 (다리가 바닥을 뚫지 않음)
- 몸에 붙은 바퀴: 체력은 안 깎지만 느려지고 시야를 가림 (털어내야 함). 한 마리가 붙거나 털어낸 뒤 3.5초 동안은 새로 붙지 않음. 털어낸 바퀴와 얼굴로 날아왔다 떨어진 바퀴는 바닥에 뒤집혀 죽음
- 늑대거미(생산 홀 벽): 벽에 붙어 있다가 빛을 비추거나 6m 안으로 다가가면 내려와 바닥과 벽을 번갈아 기어 쫓아옴. 추격 중 빛을 비추면 가까운 벽으로 올라가 물러났다가 다시 옴. 잡히면 연타(체력 -1) 또는 스프레이, 떨쳐내면 한동안 벽으로 돌아감. 홀을 벗어나면 자기 자리로 돌아감. 추격 속도도 지네처럼 가까우면 느리고 멀면 빠름
- 유령거미(연결 복도): 머리 높이에 거의 안 보이는 실 6가닥 → 웅크려서 통과. 실을 끊으면 천장에서 내려와 벽과 바닥을 번갈아 타며 쫓아옴. 빛을 비추면 잠깐 움츠림(점점 짧아짐), 잡히면 연타, 멀어지면 천장으로 돌아가 다시 잠
  - 진짜 유령거미처럼 알집을 입에 물고 다님. 처음 스프레이를 맞거나 연타로 떨쳐내면 알집을 떨어뜨리고, 바닥에서 터진 알집에서 손바닥만 한 새끼 36마리가 발밑을 스쳐 지나가 벽 틈으로 흩어짐 (달라붙지도, 다치게 하지도, 느려지게 하지도 않음, 스프레이에 말려 죽음)
- 거미줄 함정(실험실 문): 걸리면 느려지고 늑대거미가 깨어남, 스프레이로 녹이기
- 비상 통로 입구(창고 서쪽 문): 큰 유령거미가 두꺼운 거미줄로 막고 있음. 다가가면 거미줄 위에서 몸을 떨며 위협, 스프레이로도 안 녹고 지나갈 수 없음. 바로 앞(1.4m)까지 가면 거미줄에서 튀어나와 붙잡음: 다른 거미처럼 연타로 버티거나(체력 -1) 스프레이로 떼어내야 하고, 벗어나면 뒤로 밀려나며 6초 동안은 다시 안 잡음. 발전기 3개를 다 켜면 사라지고 찢긴 거미줄만 남음
- 정전: 발전기를 켤 때마다 3초 동안 손전등까지 모든 불이 나감. 처음엔 그 사이 눈앞에 유령거미가 줄을 타고 내려와 있다가 빛을 받으면 올라가 사라지고, 불이 돌아오면 가까운 바퀴 떼가 바로 앞까지 와 있음
- 먼저 들어온 방역팀원: 연결 복도 천장에 같은 방역복 차림으로 거미줄에 감겨 거꾸로 매달려 있고, 바닥엔 그 사람 손전등이 아직 깜빡임. 일지는 그 사람이 남긴 방역 일지(옆 테이블에 마지막 쪽지)
- 숨는 곳: 웅크린 채 테이블·컨베이어 밑으로 기어 들어가기 (생산 홀 컨베이어 3줄, 기계실 작업대, 창고·복도·홀·실험실 철제 테이블). 숨는 곳마다 먼저 온 팀이 놓고 간 야광봉이 바닥에서 희미하게 빛나고, 근처에 가면 주변을 약하게 비춰서 숨어 있을 때 바깥을 두리번거리는 벌레가 보임 (벌레는 이 빛을 피하지 않음)
  - 밑에서는 일어설 수 없고 기어서 천천히 움직임
  - 손전등을 끄고 잠깐 가만히 있으면 숨음: 쫓던 벌레(바퀴 떼·지네·늑대거미·유령거미·새끼 거미 전부)가 놓치고, 숨은 자리 근처를 몇 초 뒤지다 떠남
  - 불을 켜거나, 움직이거나, 스프레이를 쓰면 들킴: 가까이 있던 벌레가 다시 쫓아오고 테이블 밑으로 손을 뻗어 잡음
  - 숨어 있으면 추격 음악이 잦아들고, 뒤지는 벌레가 가까울수록 심장 소리가 빨라짐. 화면 아래에 숨음/들킴 표시
- 실험실 알집 3개: 큰 소리에 터지고 늑대거미 새끼 66마리가 이리저리 꺾고 멈칫하며 10초 동안 몰려옴(닿을 때마다 느려짐)
- 지네: 발전기 2를 켜면 홀 환풍구에서 튀어나와 추격, 빛을 머리에 비추면 경직, 안전지대 전등 밖을 맴돔, 닿으면 몸을 일으켜 얼굴 앞까지 다가와 턱을 벌리다 덮치고(약 1.3초) 사망. 추격 속도는 거리에 따라 달라짐: 가까우면 느리게(약 3.4m/s, 달리면 떼어낼 수 있음), 멀어질수록 빠르게(최대 약 6.5m/s)
- 스프레이(우클릭/Q, 폰은 스프레이 버튼): 3회 + 리필 2회, 앞쪽 3m
- 1인칭 팔: 방역복 + 니트릴 장갑, 오른손 손전등, 왼손 살충제
- 손전등을 끄면 눈이 어둠에 적응해 가까운 곳이 희미하게 보임
- 손전등 과열: 오래 켜 두면 뜨거워지면서 빛이 어두워지고(누래지고 지직거림) 손전등 머리가 희미하게 달아오름. 한계를 넘으면 꺼져서 10초 동안 식힘(식는 동안 못 켜고 금속이 똑딱거림). 평소엔 끄고 있으면 천천히 식음. 화면의 배터리 표시는 없음
- 먼저 들어온 방역팀원, 거미(늑대거미·유령거미·통로를 막은 거미)를 처음 볼 만큼 가까이 가면 시점이 그쪽으로 돌아감. 유령거미 새끼가 알집에서 쏟아져 나올 때와 벽 틈으로 흩어질 때도 혼잣말과 함께 시점이 따라감
- 화면에 뜨는 말은 대부분 주인공의 혼잣말 ("손전등이 과열되었다", "손전등이 아직 뜨겁다", "소리를 듣고 오는 건가... 몸을 낮추고 걷자" 등)
- 효과음·환경음·추격 긴장음 (전부 코드로 합성): 다침, 부활, 리필, 떨쳐냄, 거미가 깨어남·움찔함, 바퀴 죽음, 알집 떨어짐, 손전등 지직거림·배터리 다 됨, 웅크릴 때 옷 소리, 탈출 등
- 입체 음향: 가까운 벌레는 한 마리씩 자기 발소리가 있어서 이어폰을 끼면 어느 쪽에 있는지 들림 (뒤에 있으면 소리가 먹먹해짐)
- 개발자 모드(F1로 버튼 표시): 방/벌레 위치 순간이동, 무적·벽 통과·벌레 멈춤 등
- 벌레 모델: 바퀴벌레(날기 포함), 그리마형 지네, 늑대거미·유령거미


## 1인칭 손 (게임에 적용됨, 따로 보기도 가능)

`docs/hands.html` · https://kimarthur815-collab.github.io/mandible/hands.html

- 파란 니트릴 장갑 + 흰 방역복 소매(손목 고무줄 주름) + 검은 전술 손전등, 전부 코드로 생성
- 손: 거리장(SDF)으로 만든 장갑 모양을 메시로 바꾸고 뼈 17개에 스키닝. 손가락이 쥔 물체에 닿을 때까지 감기는 방식으로 쥐는 모양을 계산
- 장갑 디테일: 펴진 손가락 마디엔 잔주름, 굽히면 손바닥 쪽 접힘, 손끝 미끄럼 방지 질감
- 게임에서 쓰는 포즈 4개: 기본 · 왼손 사용 · 손전등 끄기 · 스프레이
- 오른손은 레퍼런스 사진처럼 손등이 오른쪽을 보게 쥐고, 손목을 살짝 아래로 꺾어 손전등이 앞을 향함
- 게임 시점(어두운 방) / 스튜디오(돌려보기)
- 게임: 이 손을 그대로 사용 (오른손 손전등, 왼손은 늘 스프레이 캔, 뿌릴 때 캔을 들어 올림). 팔은 54° 화각의 별도 카메라로 그려 뷰어와 똑같이 보임
- 손전등 빛: 가운데가 밝고 가장자리가 부드러운 빛 무늬 + 빛줄기, 가까운 벽을 비추면 빛을 줄여 하얗게 타지 않음
