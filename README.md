# MANDIBLE

버려진 살충제 공장에서 거대한 벌레들을 피해 탈출하는 1인칭 3D 공포 게임.
방역업체 직원이 되어 발전기 3개를 켜고, 약 4분 안에 하역장 셔터로 빠져나가야 한다.

Three.js로 웹에서 바로 돌아가며, 폰(가로 화면)과 PC 모두 지원한다.

### 조작

**PC**: WASD 이동 · 마우스(좌클릭) 화면 전환 · 우클릭(F) 손전등 · T 스프레이 · Shift 달리기 · Ctrl 앉기(한 번 누르면 앉고 다시 누르면 일어남, 폰 앉기 버튼도 같음) · E 상호작용(발전기는 E 꾹 누르기) · R 무전(본부에 길 묻기, 3번) · G 빈 캔 던지기 · V 카메라 · M 지도 · J 수첩(벌레 기록) · F1 개발자 도구(개발·벌레 위치·밝게 버튼 표시/숨김, 표시 중엔 ` 개발자 모드, B 밝게 보기)

**폰**: 가로로 들고 플레이. 왼쪽 화면을 끌어 이동, 오른쪽 화면을 끌어 둘러보기. 바퀴가 몸에 붙거나 거미에게 잡히면 화면 아무 데나 연타. 할 일을 알려주는 대사엔 괄호로 조작이 붙음 — 폰에서도 PC 키까지 같이 보임, 예: '앉아서 숨자 (앉기 Ctrl)' (폰에서는 줄바꿈되어 버튼에 가리지 않음).

**설정**(오른쪽 위 '설정', 시작 화면에서도 가능): 난이도, 시점 감도, 소리 크기, 밝기, 화질(낮음은 그림자 끔), 화질 자동 조절 켜기/끄기, 자막 크기, 화면 흔들림 켜기/끄기, 새 벌레 기록 펼치기 켜기/끄기(끄면 새로 찾은 수첩 페이지가 눈앞에 펼쳐지지 않고 옆에 작게만 뜸 — 펼쳐진 페이지의 '다음부턴 안 펼치기' 버튼으로도 끌 수 있음), 힌트 혼잣말 켜기/필요한 것만('필요한 것만'이어도 꼭 알아야 하는 안내는 뜸: 손전등 켜기, 숨는 법(앉아서 테이블·컨베이어 밑, 불 끄고 가만히), 늑대거미 숨기 안내, 실·거미줄·알집 지나가는 법, 손전등 과열, 환기구로 도망가기와 덕트 안 길), 진동(안드로이드 폰만). 이 브라우저에 저장됨.

**난이도**: 거미·지네에게 잡혀도 쉬움·보통에서는 연타로 버티면 체력 손실 없이 풀려남(지네도 쉬움·보통에선 몸을 감은 뒤 연타나 스프레이로 빠져나올 수 있음, 힘이 다하면 체력 -1). 어려움에서는 버텨도 체력 -1, 힘이 다하거나 지네에게 잡히면 사망. 쉬움(체력 5 · 스프레이 5 · 벌레가 느리고 발소리를 덜 들음 · 손전등이 천천히 뜨거워짐 · 시동줄 초록 칸이 넓음 · 잡혔을 때 버티기 쉬움) / 보통(체력 3 · 스프레이 3) / 어려움(체력 2 · 스프레이 2 · 지네와 거미가 더 빠름 · 발소리가 멀리 퍼짐 · 손전등이 빨리 뜨거워짐 · 초록 칸이 좁고 빠름). 체력과 스프레이 수는 새로 시작할 때 적용.

**지도**(M / 지도 버튼): 튼튼한 태블릿을 들어 보는 미니맵. 나를 가운데에 두고 바라보는 쪽이 위로 오게 돌아가며, 방·문·잠긴 문(빨간 점선)·지금 있는 방 이름·켠 발전기 수가 보임. 화면이 밝아서 어둠 속에서도 보이고, 보는 동안 조금 느려짐. 쉬움은 발전기(빨강 꺼짐/초록 켜짐)·전등·출구와 화면 밖 발전기 방향 화살표(거리), 보통은 발전기와 화살표, 어려움은 도면과 내 위치만. 한참 길을 못 찾고 헤매면 '패드로 지도를 보자' 혼잣말이 나옴. 마지막 발전기 뒤로 2분 반이 지나도록 헤매고 있으면 '무전으로 본부에 길을 물어보자' 혼잣말과 함께 무전 버튼이 깜빡임(무전이 남아 있을 때, 최대 3번)

**개발자 도구**: 개발·벌레 위치·밝게 버튼은 숨겨져 있음. PC는 F1, 폰은 '설정' 버튼을 1.5초 꾹 누르면 나타나고 다시 하면 숨음.

### 전체화면

- **PC · 안드로이드**: 오른쪽 위 '전체화면' 버튼 (PC는 F11도 가능). 폰은 게임 시작할 때 자동으로 전체화면 + 가로 고정을 시도한다.
- **아이폰**: Safari는 웹페이지 전체화면을 지원하지 않는다. Safari로 열고 **공유 → 홈 화면에 추가** 후, 홈 화면의 MANDIBLE 아이콘으로 실행하면 주소창 없이 전체화면으로 플레이된다.

  - 실험실 문(홀 쪽 출입구, 철제 미닫이): E로 닫고 열 수 있음. 지네에게 쫓기며(쫓는 중·찾는 중·문밖을 서성이는 중, 15m 안) 실험실에 들어서면 문을 지나는 순간 저절로 쾅 닫힘('문을 쾅 닫았다!', 들어올 때마다 한 번, 안에서 다시 열면 그대로 열려 있음). 문이 열려 있는 동안 지네는 실험실에 안 들어오고 문 밖 홀에서 왔다 갔다 하며 고개를 두리번거림(문 앞까지 나가면 덮침). 문을 닫으면 문 밖에서 긁고 두드리다가, 덮개가 떨어지는 소리를 듣거나 22초가 지나면 문을 계속 들이받아(약 9초) 부수고 들어옴
  - 비상 통로 문은 고장('안 열림')이라 환기구로 기어 들어가야 함(다가가면 저절로 엎드림). 덕트 안은 손전등 빛이 바로 앞 금속에 부딪혀 덜 밝게 보이고 바람 소리가 남. 덕트 안(과 떨어지는 동안)은 환풍기 바람에 손전등이 식어서 과열되지도 꺼지지도 않음(과열돼 꺼진 채 들어오면 바로 다시 켜짐). 입구에서 지네가 들이받으러 오면(들어갈 때 지네가 11m 안에 있었으면) 먼저 입구 바로 밖까지 와서 기다리다가, 덕트 안으로 3m 기어 들어갔을 때(또는 6초 뒤) 머리를 덕트 안으로 1m쯤 들이밂. 그 순간 시점이 입구 쪽으로 돌아가 조금 확대된 채 붙잡힘: 1.8초 물어뜯다 물러날 때까지(최대 4.2초, 그동안 못 움직임), 그다음 0.7초 동안 다시 덕트 안쪽(가던 방향)으로 돌려놓음. 지네 머리는 덕트를 따라 나와 1.4m 넘게 가까워지지 않음(6초 동안 입구 바로 안에 있으면 입구 밖에서 물어뜯음). 덕트 바깥벽을 따라오는 다리 소리는 지네가 물러난 1초 뒤부터
  - 지네가 바로 뒤에 있었으면 환기구에 머리를 처박고 턱을 딱딱거리다 왔던 길로 뒷걸음쳐 사라짐('못 들어온다... 덩치가 너무 크다')
  - 그 뒤로 덕트 바깥 벽을 따라 다리 소리와 쾅쾅 두드리는 소리가 따라오다 앞질러 가고, 꺾이는 곳에서 조용해졌다가 바로 앞 벽을 두 번 들이받음: 철판이 안쪽으로 불룩 찌그러지고 발톱 구멍이 뚫림(시점이 찌그러지는 쪽으로 돌아감)
  - 오른쪽으로 꺾어 가다 보면 옆 철망을 쳐내고 머리를 덕트 안으로 들이밂(시점이 그쪽으로 돌아감): 손전등을 머리에 1초쯤 비추거나 스프레이를 뿌리면 물러남, 그냥 지나가려 하면 물림(체력 -1, 뒤로 밀려남), 오래 기다려도 결국 물러남
  - 끝의 바닥 철망 아래로 하역장 불빛이 새어 올라옴. 그 위로 기어가면 철망이 삐걱이다 꺼지고 떨어짐 → 잠깐 암전 → 하역장 천장 환기구로 떨어져 바닥에 쿵(철망도 같이 떨어짐), 셔터 쪽을 보며 일어남('셔터가 열려 있다... 뛰어!')
  - 일어나자마자 하역장 서쪽 벽 환기구를 터뜨리고 지네가 튀어나와 쫓아옴: 열린 셔터까지 달리면 탈출
  - 덕트에서 다시 나가면 지네가 다시 찾아다님. 죽었다 살아나면 덕트를 다시 기어갈 수 있음(이미 일어난 일은 다시 안 일어남)
  - 무전으로 길을 물으면 환기구 방향(덕트 안이면 '계속 기어가라'), 지도에는 덕트 길과 하역장까지 이어지는 점선, 화면 밖이면 환기구 방향 파란 화살표
- 한 구역씩: 그 구역 발전기를 켜기 전엔 다음 구역으로 가는 문에 출입금지 테이프가 쳐져 있어 못 지나감(기계실 발전기 → 복도, 생산 홀 발전기 → 실험실). 다가가면 '아직 기계실 발전기를 안 켰다. 먼저 켜고 가자'
- 발전기 시동줄: E(폰은 손 버튼)를 꾹 누르고 있으면 시동줄을 몇 번 당기다 시동이 걸림(쉬움 1.8초 · 보통 2.4초 · 어려움 3초). 손을 떼면 게이지가 다시 줄어듦. 시동 소리가 커서 주변 벌레가 몰려옴
- 2조의 야광 스프레이: 먼저 들어온 2조가 벽과 바닥에 스프레이로 길을 표시해 둠 — 초록 '발전기' 화살표(하역장 → 창고 → 기계실 → 복도 → 생산 홀 → 실험실), 주황 경고('X 거미!! 가지 마', '실 조심! 앉아서 지나가', '위에 알집! 조용히'), 파란 '출구' 화살표(실험실 벽 '출구 환기구' → 덕트 안 바닥), 비상 통로 문엔 'X 안 열림'. 야광 페인트라 손전등을 비추면 밝게 빛나고, 불을 돌린 뒤에도 몇 초 동안 은은하게 남음. 처음 보면 '이걸 따라가면 되겠다' 혼잣말
- 무전: 발전기를 켤 때마다 본부 무전(남은 대수, 마지막엔 '당장 나와. 실험실 환기 덕트가 하역장 위로 이어진다'). 가끔 지직거림 속에 이상한 목소리가 섞여 들어옴(최대 3번)
- 2조 이정훈의 녹음기 4개(창고·기계실·홀·실험실 테이블, 빨간 불 깜빡임): 재생하면 먼저 들어온 사람의 목소리 기록이 자막과 함께 나옴 — 실제 남자 목소리로 녹음된 대사(한국어 음성 합성 Supertonic-2의 M2 목소리, 낡은 녹음기처럼 지직거리고 목소리 자체도 살짝 깨짐, docs/voice/*.mp3, 약 0.6MB)이고 자막은 녹음 길이에 맞춰 넘어감. 실험실 테이프는 '셔터로 바로—'에서 말이 뚝 끊기고, 시체 옆 마지막 테이프는 거친 숨으로 시작해 '집사람한테 좀...' 뒤 다리가 마이크를 긁다 끊김. 환풍구·지네가 흉내 내는 그의 목소리도 같은 목소리(벽 속에서 울리고 끝이 처지며 딸깍 소리). 녹음 파일을 못 받으면 예전처럼 합성 웅얼거림. 무전·녹음은 겹치지 않고 차례로 나옴
- 본부 무전도 실제 목소리(Supertonic-2의 M3 남자 목소리, 무전기처럼 좁은 대역에 지직거림, docs/voice/hq_*.mp3, 약 0.5MB): 오프닝 통화, 발전기 무전, 길 묻기, 엔딩까지 전부. 길 묻기처럼 방·방향·거리가 바뀌는 대사는 조각(예: '실험실 발전기가 아직이다.' + '왼쪽 앞 방향,' + '15미터쯤.')을 이어 붙여 말함(src/map/hqvox.js). 자막은 목소리 길이에 맞춰 넘어가고, 오프닝·엔딩에서 탭해서 넘기면 말이 끊김. 오프닝 첫마디는 페이지가 열릴 때 미리 받아 둠(아직 못 받았으면 2초까지 기다렸다 말함). 엔딩의 '......3...조... 들리나... 여기... 2조...'와 중간의 이상한 무전 '...안에... 아직...'은 본부가 아니라 이정훈(M2) 목소리가 더 심하게 끊기며 나옴. '치익————'·'(지직거림 속에...)'·'(사각사각...)'은 예전 합성음. 파일을 못 받으면 예전처럼 합성 웅얼거림
- 쪽지: 공책에서 찢은 구겨진 종이가 작업대 위에 놓여 있고, 읽으면 손글씨(볼펜, 줄 공책, 커피 자국, 지운 단어)로 보임
- 엔딩: 셔터 밖으로 나가면 밤 마당을 걸어 트럭에 다시 타고, 본부에 무전 → 지직거림 속 2조 목소리 → 마이크 위를 뭔가 기어 다니는 소리(사원증을 가져왔으면 본부와 통화하고 사원증 뒤의 '셔터 열리면 뒤돌아보지 마' 메모) → 정적 속에 좌석 밑에서 바스락 소리, '...?' → 백미러를 올려다보면 두 좌석 사이로 털 난 거미가 눈을 빛내며 올라오고, 딸깍거리다 덮쳐 와 비명과 함께 암전 → 결과 화면 (화면/엔터로 다음 줄, 건너뛰기 가능)
- 2조 이정훈의 수첩: 새 벌레(바퀴, 유령거미, 늑대거미, 통로 막은 거미, 알집, 지네)를 처음 만나면 그 벌레를 도감처럼 정밀하게 그린(해칭·점묘·지시선·축척·확대 그림) 수첩 한 장이 생김. 종이는 훼손돼 있음: 찢긴 모서리, 탄 자국, 핏자국과 지문, 물 얼룩과 번진 잉크, 테이프, 곰팡이. 처음 한 번은 그 장이 메모처럼 눈앞에 펼쳐지고 게임이 멈춤('2조 이정훈의 수첩 · 새로 찾은 기록', 1.3초 뒤부터 '다 읽었다'로 닫힘; 잡혀 있거나 쫓기거나 시점이 끌려가는 중이면 끝난 뒤에 나옴). 그 뒤로는 J 또는 수첩 버튼으로 펼쳐서 넘겨 볼 수 있음
- 지네에게 잡히면(약 2.6초): 얼굴 앞으로 솟구침 → 넘어지고 → 끌려가며 지네가 몸을 둘러 감음 → 떨어진 손전등 불빛 속에 머리가 위에서 천천히 내려옴(다리가 화면을 덮고 심장 소리) → 물림 → 사망
- 무전(R / 무전 버튼, 한 판에 3번): 본부가 아직 안 켠 가장 가까운 발전기(다 켰으면 실험실 환기구, 하역장이면 셔터)가 어느 쪽, 몇 미터쯤인지 알려 주고, 쫓기거나 다쳤을 때 등 상황에 맞는 한마디를 덧붙임. 무전 소리가 커서 근처 벌레가 들음
- 방독면: 트럭에서 쓴 방독면 때문에 게임 내내 화면 가장자리가 어둡고 아래쪽에 코 부분 그림자가 짐. 방독면 너머로 숨소리(필터로 들이쉬는 쉭 소리, 배기 밸브가 딸깍 열리며 내쉬는 소리)가 들리고 내쉴 때마다 유리가 살짝 뿌옇게 김이 서림 — 평소엔 느리게, 달려서 지치거나 뭔가에 쫓기면 빠르고 거칠게. 숨어 있을 땐 숨을 참았다가(조용) 나오면 크게 내쉼. 탈출해서 밖으로 나오면 벗음
- 추격 음악: 거미나 지네에게 발견되는 순간 '쾅' 하는 경고음과 금관 같은 저음, 쫓기는 동안 북·저음·금속음 리듬이 깔리고 가까울수록 빨라지고 겹이 늘어남 — 16분음표로 몰아치는 현악, 백비트 스네어, 두 마디마다 묵직한 금관, 네 마디마다 치솟는 소리와 북 필인, 틱틱 소리와 비명 같은 현. 마디마다 반음씩 올라감. 놓치고 찾는 중엔 낮은 박동만 남고, 따돌리면 풀리는 소리. 숨어 있으면 작아짐. 지네에게 쫓길 땐 지네만의 추격 음악 — 공장 배경음악의 7박자 기계 리듬(레 레 미♭)이 전속력으로 돌고 공장 선율을 금관이 크게 불며, 가까울수록 묵직한 저음·합창·비명 같은 현이 더해짐
- 배경음악(전부 코드로 합성): 시작 화면은 노을 진 드라이브 — 따뜻하고 조금 쓸쓸한 일렉 피아노 선율과 패드(무전을 받는 동안은 작아짐, 매 바퀴 끝에 살짝 불길한 화음). 밤 공장 마당은 귀뚜라미·바람·낮은 웅웅거림·유리 같은 소리. 공장 안은 건물 어딘가에서 7박자(3+2+2)로 쿵… 쿵 쿵 도는 기계와 낮은 웅웅거림, 그 위에 차가운 비브라폰 선율(레–라–시♭–도#) — 처음엔 멀리서 먹먹하게 들리다가 발전기를 켤수록·벌레가 가까울수록 가까워지고 빨라지며 쇳소리, 증기, 째깍거림, 한 옥타브 위 선율과 어긋난 메아리, 묵직한 저음이 차례로 더해짐. 쫓길 땐 추격 음악에 자리를 내주고, 숨으면 작아짐. 발전기 3 뒤 환기구에 들어가면 탈출 음악으로 바뀜 — 덕트에선 떨리는 저음 현악·허밍 합창·조금씩 커지는 팀파니, 첼로 혼자 공장 선율을 켬 → 떨어질 땐 팀파니 연타와 치솟는 소리 → 착지하는 순간 쾅 하고 셔터까지 말 달리듯 6/8박 현악·팀파니·합창·금관 찬송 → 셔터를 빠져나가면 합창이 D장조로 풀리고 종소리가 마당까지 울림(탈출 중엔 추격 음악 대신 이 음악). 엔딩 드라이브는 시작 화면 선율을 더 느리고 어둡게
- 전등 체크포인트: 레버로 켠 전등이 저장 지점. 20초 뒤 꺼져도 몇 번이든 다시 켤 수 있음(켜져 있을 때 당기면 20초가 처음부터). 죽으면 그 전등 옆에서 체력 3으로 다시 일어나고, 전등이 10초 다시 켜짐. 진행(발전기·쪽지·리필·끊긴 실·알집·죽은 바퀴)은 유지, 스프레이는 남은 만큼, 벌레는 원래 자리로
- 바퀴 떼 4무리(10·8·7·6마리): 벽을 돌아서 길을 찾고, 지그재그·곡선으로 움직임. 빛에 닿으면 흩어져 물러나고(가끔은 날아서 도망). 쫓아오는 중이 아닐 때 5초 넘게 못 본 무리를 비추면 처음 1초는 도망가지 않아서 볼 수 있음, 빛으로 몇 초 막아내면 포기하고 둥지로 돌아감. 오래 쫓아오지 않음
- 스프레이 맞은 바퀴: 뒤집힌 채 바닥에 남아 계속 다리를 버둥거림
- 스프레이 맞은 거미: 배를 위로 하고 뒤집혀 다리를 위로 오므린 채 버둥거림 (다리가 바닥을 뚫지 않음)
- 몸에 붙은 바퀴: 체력은 안 깎지만 느려지고 시야를 가림 (털어내야 함: PC는 마우스 흔들기·클릭 연타, 폰은 화면을 좌우로 흔들기·연타) — 붙는 순간 '얼굴에 붙었다! 화면을 좌우로 흔들어 떼어내!'(PC는 '마우스를 흔들어') 대사가 뜨고, 계속 붙어 있으면 5초마다 '빨리! 화면을 마구 흔들어!'. 얼굴 위 바퀴는 바퀴 미리보기의 정밀 모델로, 몸을 타고 아래에서 기어 올라와 눈앞을 돌아다님(배·다리 관절·입·더듬이가 보임). 붙어 있는 내내 온몸을 부르르 떨고(멈춰 있을 땐 더 심하게, 가끔 날개를 반쯤 펴고 파르르), 배가 펌프질하듯 벌떡이고, 입이 쉴 새 없이 움직이고, 다리 발톱이 긁어 댐. 붙어 있는 동안 화면이 내내 부들부들 흔들리고 가끔 크게 움찔함(여러 마리 붙었거나 털어내는 중엔 더 세게, 설정에서 화면 흔들림을 끄면 안 흔들림), 뒤쪽 세상은 초점이 나가 흐려짐. 털어내면 화면 밖으로 허둥지둥 도망감. 얼굴로 날아오는 바퀴도 맞는 순간 같은 모델로 보임. 발밑에 바퀴가 5마리 넘게 모이면 시점이 저절로 발밑을 봄(12초에 한 번). 한 마리가 붙거나 털어낸 뒤 3.5초 동안은 새로 붙지 않음. 털어낸 바퀴와 얼굴로 날아왔다 떨어진 바퀴는 바닥에 뒤집혀 죽음
- 늑대거미(생산 홀 벽): 처음엔 홀 발전기 바로 뒤 북쪽 벽(높이 2.6m)에 붙어 있음. 18m 안에서 처음 눈에 들어오면 시점이 거미 쪽으로 돌아가 확대되며 2.6초 동안 보여 줌(그동안 못 움직이고, 보여 주는 동안엔 안 깨어남) + '저 벽에... 큰 거미가 붙어 있다. 들키면 컨베이어 밑에 숨자'. 처음 깨어날 때는 짧은 컷신: 시점이 벽에서 내려오는 거미를 확대해 보여 준 뒤 가장 가까운 컨베이어 밑을 비춤(2.7초, 그동안 거미는 기다림). 벽에 붙어 있다가 빛을 비추거나 6m 안으로 다가가면 내려와 바닥과 벽을 번갈아 기어 쫓아옴. 느리지만 끈질김: 빛을 비춰도 잠깐 움찔하고(4초에 한 번) 비추는 동안 느려질 뿐이고, 3.5초 넘게 계속 비춰야 가까운 벽으로 잠깐(1.5~2.5초) 올라갔다가 다시 옴. 잡히면 연타 또는 스프레이, 떨쳐내면 잠깐 벽으로 돌아감(3초 뒤엔 다시 쫓아옴). 거미에게 잡혔다 풀려나면 4초 동안은 다시 안 잡힘. 홀을 벗어나도 10초 동안은 기다리다가 자기 자리로 돌아가고, 돌아가는 길에 7m 안으로 다가가면 다시 돌아서서 쫓아옴. 숨으면 14~18초 동안 주변을 뒤짐. 숨는 법을 확실히 알려 줌: 깨어날 때 '앉아서 컨베이어 밑에 숨자', 홀에서 쫓기는 중엔 5초 뒤부터 12초마다(최대 4번) '컨베이어 밑으로! 앉아서 기어 들어가자'(밑에 들어가 있는데 불이 켜져 있으면 '불 끄고 가만히!'), 본부 무전·수첩 페이지도 같은 내용. 추격 속도는 가까우면 걷는 것보다 조금 느리고 멀면 빨라짐. 홀은 높은 창으로 드는 빛이 전체적으로 조금 밝게 있고, 고장 난 형광등(한쪽 사슬이 끊겨 기울어짐) 7개가 매달려 있음: 홀에 들어서면 거미 쪽 형광등이 '틱' 소리와 함께 깜빡이며 켜져 거미를 비추고(거미가 옮겨 가면 그쪽이 켜짐), 나머지도 가끔 하나씩 깜빡이다 몇 초 켜졌다 꺼짐
- 유령거미(연결 복도): 머리 높이에 실 6가닥 → 앉아서 통과. 그리고 발목 높이(12~18cm)에 실 1가닥(끝쪽, 마지막 실 바로 앞): 앉거나 뛰어서 지나가면 끊어지고, 서서 걸어 넘어가면 괜찮음. 처음 다가가는 실(그리고 발목 높이 실)은 3m 앞에서 시점이 그 실로 돌아가 확대되며 2.4초 보여 주고 지나가는 법을 알려 줌(혼잣말을 꺼도 나옴). 실은 손전등 빛(가장자리까지)에 반짝이는 몇 픽셀 굵기 선과 먼지 방울로 보임(거미가 매달린 줄도 같은 방식). 실을 끊으면 천장에서 내려와 벽과 바닥을 번갈아 타며 쫓아옴. 빛을 비추면 잠깐 움츠리며 살짝 떪(점점 짧아짐), 잡히면 연타, 멀어지면 천장으로 돌아가 다시 잠
  - 진짜 유령거미처럼 알집을 입에 물고 다님. 처음 스프레이를 맞거나 연타로 떨쳐내면 알집을 떨어뜨리고, 바닥에서 터진 알집에서 손바닥만 한 새끼 36마리가 발밑을 스쳐 지나가 벽 틈으로 흩어짐 (달라붙지도, 다치게 하지도, 느려지게 하지도 않음, 스프레이에 말려 죽음)
- 빈 살충제 캔(맵 곳곳 9개, 3개까지 들 수 있음): G(폰은 던지기 버튼)로 던지면 날아가 튕기며 굴러가고, 처음 부딪힌 곳에서 큰 소리 → 근처 바퀴 떼가 그쪽으로 몰려가고, 지네·늑대거미도 (나를 똑바로 쫓는 중이 아니면) 소리 난 곳을 뒤지러 감. 떨어진 캔은 다시 주울 수 있음
- 2조의 일회용 카메라(창고 테이블, 3장): V(폰은 카메라 버튼). 플래시에 바퀴는 흩어지고, 유령거미는 한참 움츠리고, 늑대거미는 벽으로 도망가고, 지네는 잠깐 굳음. 잡혔을 때 쓰면 풀려남. 찍힌 벌레 사진(날짜 찍힌 필름 사진)이 수첩 그 벌레 페이지에 테이프로 붙음
- 이정훈 찾기: 생산 홀 북서쪽 구석, 벽에 뚫린 구멍으로 발부터 끌려 들어가다 만 이정훈. 옆에 아직 켜진 손전등, 마지막 녹음(5번째 녹음기), 사원증. 11m 안에서 정면으로 보일 때 '저기... 누가 쓰러져 있다' + 시점이 그쪽으로(벽뿐 아니라 물탱크·기계·상자처럼 앞을 가리는 것이 있으면 발견 안 됨: 충돌 상자를 바닥부터 그 높이까지의 상자로 보고 시선이 지나가는지 검사). 사원증을 챙겨 탈출하면 엔딩 무전이 바뀜(진엔딩: 본부에 보고하고, 사원증 뒤에 적힌 이정훈의 마지막 글)
- 환각: 아무도 없는데 무전에서 '...뒤에...' 속삭임 + 바로 뒤에서 뭔가 지나가는 소리, 사람처럼 세워 둔 빈 방역복이 볼 때마다 다른 곳(창고 → 기계실 → 복도 → 홀 → 실험실)에 서 있음, 손전등이 떨리는 동안에만 빛 끝에 보이는 길쭉한 형체 (전부 한 판에 한두 번, 해치지는 않음)
- 더 무서운 것들(해치지는 않음):
  - 이정훈 목소리: 그의 녹음을 하나라도 들었으면, 지네가 아직 벽 속에 있을 때 생산 홀 환풍구에서 '...3조... 여기야...', 잠시 뒤 '...도와줘...' 하고 그의 목소리가 들림(벽 속처럼 먹먹하게 울리고 끝에 딸깍거리는 소리). 다가가면 덮개가 덜컹거리고 쉿 소리 — '...이정훈 씨는... 저기 죽어 있었는데.' 지네가 나온 뒤엔 가끔(최대 3번) 안 보이는 곳에 있는 지네 쪽에서 '...이쪽이야...' '...살려 줘...' '...셔터... 이쪽으로 와...' — 따라가면 지네가 있음
  - 숨어 있으면(3.5~6초 뒤, 70% 확률, 45초에 한 번) 바로 옆으로 뭔가 기어 와 멈춰서 킁킁대다 지나감 — 지나갈 때 야광봉 빛이 가려짐
  - 손전등: 거미나 지네가 10m 안에 있으면(안 보여도) 지직거리며 깜빡임, 가까울수록 자주
  - 지네가 아직 벽 속에 있을 때(최대 2번) 천장 위로 뭔가 무거운 게 쿵쿵 기어 지나가며 머리 위로 먼지가 떨어지고 화면이 살짝 울림 — '...위에... 뭐가 지나갔어.'
- 결과 화면: 시간·다친 횟수·쓰러진 횟수·스프레이·캔·사진·무전·수첩·녹음·사원증 기록과 S~C 등급, 난이도별 최고 기록. 도전과제 10개(무사히, 맨손, 무전 침묵, 딴 데 봐, 찰칵, 기록 수집가, 이정훈, 5분 컷, 어려움 등) — 이 브라우저에 저장
- 시점이 벌레 쪽으로 끌려갈 때(처음 보는 거미, 통로 막은 거미, 알집이 터질 때, 발밑 바퀴 떼, 발밑 늑대거미 새끼 떼, 정전 때 유령거미): 높은 바이올린 현을 세게 긁는 소리가 한 번(반음씩 어긋난 화음이 올라붙었다 떨리며 처짐)
- 진동(안드로이드): 바퀴가 붙을 때, 잡힐 때, 다칠 때, 지네에게 잡힐 때, 발전기·정전, 쫓길 때 심장 박동
- 거미줄 함정(실험실 문): 걸리면 느려지고 늑대거미가 깨어남, 스프레이로 녹이기
- 비상 통로 입구(창고 서쪽 문): 큰 유령거미가 두꺼운 거미줄로 막고 있음. 다가가면 거미줄 위에서 몸을 떨며 위협, 스프레이로도 안 녹고 지나갈 수 없음(끝까지 안 비켜 줌). 바로 앞(1.4m)까지 가면 거미줄에서 튀어나와 붙잡음: 다른 거미처럼 연타로 버티거나(체력 -1) 스프레이로 떼어내야 하고, 벗어나면 뒤로 밀려나며 6초 동안은 다시 안 잡음
- 정전: 발전기를 켤 때마다 3초 동안 손전등까지 모든 불이 나감. 처음엔 발전기를 켜는 순간부터 손전등이 돌아와 거미가 올라갈 때까지 시점이 고정돼(움직이기·화면 돌리기 안 됨, 컷신처럼 내려올 자리를 향해 고개가 돌아감) 그 사이 눈앞에 유령거미가 줄을 타고 내려와 있다가, 불이 들어오는 순간 화면이 흔들리고 바이올린 소리, 빛을 받으면 올라가 사라지고, 불이 돌아오면 가까운 바퀴 떼가 바로 앞까지 와 있음. 이 장면이 시작될 때 얼굴에 붙어 있던 바퀴는 떨어지고, 장면 동안(그리고 시점이 붙잡혀 있는 다른 장면 동안)은 바퀴가 새로 붙거나 얼굴로 날아들지 않음
- 먼저 들어온 방역팀원: 연결 복도 천장에 같은 방역복 차림으로 거미줄에 감겨 거꾸로 매달려 있고, 바닥엔 그 사람 손전등이 아직 깜빡임. 일지는 그 사람이 남긴 방역 일지(옆 테이블에 마지막 쪽지)
- 숨는 곳: 앉은 채 테이블·컨베이어 밑으로 기어 들어가기 (생산 홀 컨베이어 3줄, 기계실 작업대, 창고·복도·홀·실험실 철제 테이블). 숨는 곳마다 먼저 온 팀이 놓고 간 야광봉이 바닥에서 희미하게 빛나고, 근처에 가면 주변을 약하게 비춰서 숨어 있을 때 바깥을 두리번거리는 벌레가 보임 (벌레는 이 빛을 피하지 않음)
  - 밑에서는 일어설 수 없고 기어서 천천히 움직임
  - 손전등을 끄고 잠깐 가만히 있으면 숨음: 쫓던 벌레(바퀴 떼·지네·늑대거미·유령거미·새끼 거미 전부)가 놓치고, 숨은 자리 근처를 몇 초 뒤지다 떠남
  - 불을 켜거나, 움직이거나, 스프레이를 쓰면 들킴: 가까이 있던 벌레가 다시 쫓아오고 테이블 밑으로 손을 뻗어 잡음
  - 숨어 있으면 추격 음악이 잦아들고, 뒤지는 벌레가 가까울수록 심장 소리가 빨라짐. 화면 아래에 숨음/들킴 표시
- 실험실 알집 3개: 큰 소리에 터지고 늑대거미 새끼 66마리가 이리저리 꺾고 멈칫하며 10초 동안 몰려옴(닿을 때마다 느려짐). 새끼 4마리 이상이 발밑(1.4m 안)에 몰리면 발밑 바퀴 떼 때처럼 시점이 아래로 내려가며 '발밑에... 거미 새끼들이 우글거린다!'(바퀴 떼와 같이 12초에 한 번)
- 지네에게 쫓기다 바로 뒤까지 오면 고개가 저절로 뒤를 돌아봤다가 돌아옴(달리는 방향은 그대로)
- 지네: 발전기 2를 켜면 홀 환풍구에서 튀어나와 추격, 빛을 머리에 비추면 경직, 안전지대 전등 밖을 맴돔, 닿으면 몸을 일으켜 얼굴 앞까지 다가와 턱을 벌리다 덮치고(약 1.3초) 사망. 추격 속도는 거리에 따라 달라짐: 가까우면 느리게(약 3.4m/s, 달리면 떼어낼 수 있음), 멀어질수록 빠르게(최대 약 6.5m/s)
- 스프레이(우클릭/Q, 폰은 스프레이 버튼): 3회 + 리필 2회, 앞쪽 3m
- 1인칭 팔: 방역복 + 니트릴 장갑, 오른손 손전등, 왼손 살충제
- 손전등을 끄면 눈이 어둠에 적응해 가까운 곳이 희미하게 보임
- 손전등 과열(쉬움은 과열 없음, 과열 중에 켜려 하면 '손전등이 아직 뜨겁다 (3초)'처럼 남은 시간이 나옴): 계속 켜 두면 보통 45초(어려움 약 35초) 만에 과열. 뜨거워지면서 빛이 어두워지고(누래지고 지직거림) 손전등 머리가 희미하게 달아오름. 한계를 넘으면 꺼져서 5초 동안 식힘(식는 동안 못 켜고 금속이 똑딱거림). 쉬움·보통은 다 식으면 저절로 다시 켜짐('손전등이 식었다. 다시 켜졌다', 숨어 있을 때는 안 켜짐). 평소엔 끄고 있으면 천천히 식음. 화면의 배터리 표시는 없음
- 먼저 들어온 방역팀원, 거미(늑대거미·유령거미·통로를 막은 거미)를 처음 볼 만큼 가까이 가면 시점이 그쪽으로 돌아감. 유령거미 새끼가 알집에서 쏟아져 나올 때와 벽 틈으로 흩어질 때도 혼잣말과 함께 시점이 따라감
- 화면에 뜨는 말은 대부분 주인공의 혼잣말 ("손전등이 과열되었다", "손전등이 아직 뜨겁다", "소리를 듣고 오는 건가... 앉아서 걷자 (앉기 Ctrl)" 등)
- 효과음·환경음·추격 긴장음 (전부 코드로 합성): 다침, 부활, 리필, 떨쳐냄, 거미가 깨어남·움찔함, 바퀴 죽음, 알집 떨어짐, 손전등 지직거림·배터리 다 됨, 앉을 때 옷 소리, 탈출 등
- 입체 음향: 가까운 벌레는 한 마리씩 자기 발소리가 있어서 이어폰을 끼면 어느 쪽에 있는지 들림 (뒤에 있으면 소리가 먹먹해짐). 폰에서는 소리가 끊기지 않게 더 가벼운 방식(좌우 패닝, 짧은 울림, 큰 오디오 버퍼)으로 처리. 배경음악은 1초, 추격 음악은 0.5초 앞까지 미리 예약해 둬서 렉이 걸려도 소리에 구멍이 안 나고, 그보다 길게 멈추면 놓친 박자만 건너뛰고 박자는 그대로 이어감. 그리고 무거운 음악(공장 기계 심장, 거미·지네 추격, 탈출)은 소리가 켜지면 뒤에서 미리 녹음해 두고(OfflineAudioContext — 강도별로 박자가 맞는 루프 몇 개: 공장 8마디×3단계, 추격 4마디×3단계, 덕트×2, 질주 16마디), 다 되면 그 루프들을 강도에 따라 섞어서 틀기만 함 — 음 하나하나 합성하던 때보다 소리 처리 부담이 거의 없어서 지네처럼 무거운 장면에서도 소리가 안 끊김(준비되기 전 몇 초는 예전처럼 실시간 합성, 공장 음악의 템포는 고정)
- 개발자 모드(F1로 버튼 표시): 방/벌레 위치 순간이동, 무적·벽 통과·벌레 멈춤 등
- 벌레 모델: 바퀴벌레(날기 포함), 그리마형 지네, 늑대거미·유령거미

### 최적화 (보이는 건 그대로)
- 방 단위로 안 보이는 것 안 그리기: 지금 있는 방과 열린 문으로 이어진 방만 그림(문간에 서 있으면 양쪽 다, 덕트는 실험실에 붙은 방). 꾸미기·벽·거미·지네·알집·시체 등이 대상이고, 손전등 그림자에도 같이 빠짐. 같은 화면을 켜고/끄고 비교해서 픽셀 차이 0 확인
- 조명 풀: 맵 곳곳의 점 조명(전등·빨간 비상등·새벽빛·덕트 불빛·카메라 플래시 등 13개)은 실제로는 안 그리고, 매 프레임 켜져 있고 보이는 방에 있는 것 중 영향 큰 5개만 진짜 조명에 옮겨 그림 → 픽셀마다 계산하는 조명 수가 16개 → 8개
- 복도 시체의 장갑 손(삼각형 10만 개)이 그림자를 안 만들고, 화면에 보일 때만 그림. 시체는 20m 넘게 떨어지면 안 그림
- 프레임이 2초 넘게 45fps 아래면 화면 선명도를 조금씩 낮춤(최대 60%까지), 여유가 생기면 20초 뒤부터 다시 올림(설정 화질보다 높아지진 않음)
- 그래도 60%에서 3초 넘게 30fps 아래면 설정 화질 자체를 한 단계 내림(높음 → 중간 → 낮음, 15초 간격), 안내 문구가 뜸. 저절로 다시 올라가진 않음. 설정의 '화질 자동 조절'을 끄면 안 내림
- 손전등 그림자는 22m까지만

```
src/            게임 코드

```

## 빌드

```
npm install
npm run build        # 모든 페이지
npm run build:map    # 게임 맵만
```

결과물은 `docs/` 에 하나짜리 HTML 파일로 나온다. 서버 없이 파일을 바로 열어도 동작한다.

## 1인칭 손 (게임에 적용됨, 따로 보기도 가능)

`docs/hands.html` · https://kimarthur815-collab.github.io/mandible/hands.html

- 파란 니트릴 장갑 + 흰 방역복 소매(손목 고무줄 주름) + 검은 전술 손전등, 전부 코드로 생성
- 손: 거리장(SDF)으로 만든 장갑 모양을 메시로 바꾸고 뼈 17개에 스키닝. 손가락이 쥔 물체에 닿을 때까지 감기는 방식으로 쥐는 모양을 계산
- 장갑 디테일: 펴진 손가락 마디엔 잔주름, 굽히면 손바닥 쪽 접힘, 손끝 미끄럼 방지 질감
- 게임에서 쓰는 포즈 4개: 기본 · 왼손 사용 · 손전등 끄기 · 스프레이
- 오른손은 레퍼런스 사진처럼 손등이 오른쪽을 보게 쥐고, 손목을 살짝 아래로 꺾어 손전등이 앞을 향함
- 게임 시점(어두운 방) / 스튜디오(돌려보기)
- 게임: 이 손을 그대로 사용 (오른손 손전등, 왼손은 늘 스프레이 캔, 뿌릴 때 캔을 들어 올림). 팔은 54° 화각의 별도 카메라로 그려 뷰어와 똑같이 보임
- 손전등 빛: 가운데가 밝고 가장자리가 부드러운 빛 무늬 + 빛줄기, 가까운 벽을 비추면 빛을 줄여 하얗게 타지 않음
