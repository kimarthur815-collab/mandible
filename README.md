# MANDIBLE

버려진 살충제 공장에서 거대한 벌레들을 피해 탈출하는 1인칭 3D 공포 게임.
방역업체 직원이 되어 발전기 3개를 켜고, 약 4분 안에 하역장 셔터로 빠져나가야 한다.

Three.js로 웹에서 바로 돌아가며, 폰(가로 화면)과 PC 모두 지원한다.

### 조작

**PC**: WASD 이동 · 마우스 시점 · 좌클릭 손전등 · 우클릭(Q) 스프레이 · Shift 달리기 · C 웅크리기 · E 상호작용(발전기는 꾹) · M 지도 · B 밝게 보기 · ` 개발자 모드

**폰**: 가로로 들고 플레이. 왼쪽 화면을 끌어 이동, 오른쪽 화면을 끌어 둘러보기. 바퀴가 몸에 붙으면 '털기!' 연타.

### 전체화면

- **PC · 안드로이드**: 오른쪽 위 '전체화면' 버튼 (PC는 F11도 가능). 폰은 게임 시작할 때 자동으로 전체화면 + 가로 고정을 시도한다.
- **아이폰**: Safari는 웹페이지 전체화면을 지원하지 않는다. Safari로 열고 **공유 → 홈 화면에 추가** 후, 홈 화면의 MANDIBLE 아이콘으로 실행하면 주소창 없이 전체화면으로 플레이된다.

## 지금 들어간 것

- 맵: 하역장 → 창고 → 기계실 → 복도 → 생산 홀 → 실험실 → 비상 통로
  - 콘크리트 바닥, 페인트 블록벽(벗겨짐·물때·녹), 타일, 거푸집 콘크리트 질감
  - 랙과 찌그러진 박스, 팔레트, 드럼통, 포대, 배관·밸브, 철골, 형광등, 케이블, 체인
  - 지게차, 컨베이어, 탱크, 실험대와 유리기구·표본병, 표지판, 얼룩·웅덩이·균열, 거미줄, 빛 속 먼지
- 발전기 3개, 전등(안전지대), 쪽지, 출구 셔터
- 전등 체크포인트: 레버로 켠 전등이 저장 지점. 죽으면 그 전등 옆에서 체력 3으로 다시 일어나고, 전등이 10초 다시 켜짐. 진행(발전기·쪽지·리필·끊긴 실·알집·죽은 바퀴)은 유지, 스프레이는 남은 만큼, 벌레는 원래 자리로
- 바퀴 떼 4무리: 벽을 돌아서 길을 찾고, 지그재그·곡선으로 움직임. 빛에 닿으면 흩어져 물러나고(가끔은 날아서 도망), 빛으로 몇 초 막아내면 포기하고 둥지로 돌아감. 오래 쫓아오지 않음
- 스프레이 맞은 바퀴: 뒤집힌 채 바닥에 남아 계속 다리를 버둥거림
- 몸에 붙은 바퀴: 체력은 안 깎지만 느려지고 시야를 가림 (털어내야 함). 털어낸 바퀴와 얼굴로 날아왔다 떨어진 바퀴는 바닥에 뒤집혀 죽음
- 늑대거미(생산 홀 벽): 벽에 붙어 있다가 빛을 비추거나 6m 안으로 다가가면 내려와 바닥과 벽을 번갈아 기어 쫓아옴. 추격 중 빛을 비추면 가까운 벽으로 올라가 물러났다가 다시 옴. 잡히면 연타(체력 -1) 또는 스프레이, 떨쳐내면 한동안 벽으로 돌아감. 홀을 벗어나면 자기 자리로 돌아감
- 유령거미(연결 복도): 머리 높이에 거의 안 보이는 실 6가닥 → 웅크려서 통과. 실을 끊으면 천장에서 내려와 벽과 바닥을 번갈아 타며 쫓아옴. 빛을 비추면 잠깐 움츠림(점점 짧아짐), 잡히면 연타, 멀어지면 천장으로 돌아가 다시 잠
  - 진짜 유령거미처럼 알집을 입에 물고 다님. 처음 스프레이를 맞거나 연타로 떨쳐내면 알집을 떨어뜨리고, 바닥에서 터진 알집에서 손바닥만 한 새끼 36마리가 발밑을 스쳐 지나가 벽 틈으로 흩어짐 (달라붙지도, 다치게 하지도, 느려지게 하지도 않음, 스프레이에 말려 죽음)
- 거미줄 함정(실험실 문): 걸리면 느려지고 늑대거미가 깨어남, 스프레이로 녹이기
- 비상 통로 입구(창고 서쪽 문): 큰 유령거미가 두꺼운 거미줄로 막고 있음. 다가가면 거미줄 위에서 몸을 떨며 위협, 스프레이로도 안 녹고 지나갈 수 없음(피해는 없음). 발전기 3개를 다 켜면 사라지고 찢긴 거미줄만 남음
- 정전: 발전기를 켤 때마다 3초 동안 손전등까지 모든 불이 나감. 처음엔 그 사이 눈앞에 유령거미가 줄을 타고 내려와 있다가 빛을 받으면 올라가 사라지고, 불이 돌아오면 가까운 바퀴 떼가 바로 앞까지 와 있음
- 먼저 들어온 방역팀원: 연결 복도 천장에 같은 방역복 차림으로 거미줄에 감겨 거꾸로 매달려 있고, 바닥엔 그 사람 손전등이 아직 깜빡임. 일지는 그 사람이 남긴 방역 일지(옆 테이블에 마지막 쪽지)
- 숨는 곳: 웅크린 채 테이블·컨베이어 밑으로 기어 들어가기 (생산 홀 컨베이어 3줄, 기계실 작업대, 창고·복도·홀·실험실 철제 테이블)
  - 밑에서는 일어설 수 없고 기어서 천천히 움직임
  - 손전등을 끄고 잠깐 가만히 있으면 숨음: 쫓던 벌레(바퀴 떼·지네·늑대거미·유령거미·새끼 거미 전부)가 놓치고, 숨은 자리 근처를 몇 초 뒤지다 떠남
  - 불을 켜거나, 움직이거나, 스프레이를 쓰면 들킴: 가까이 있던 벌레가 다시 쫓아오고 테이블 밑으로 손을 뻗어 잡음
  - 숨어 있으면 추격 음악이 잦아들고, 뒤지는 벌레가 가까울수록 심장 소리가 빨라짐. 화면 아래에 숨음/들킴 표시
- 실험실 알집 3개: 큰 소리에 터지고 늑대거미 새끼 66마리가 이리저리 꺾고 멈칫하며 10초 동안 몰려옴(닿을 때마다 느려짐)
- 지네: 발전기 2를 켜면 홀 환풍구에서 튀어나와 추격, 빛을 머리에 비추면 경직, 안전지대 전등 밖을 맴돔, 닿으면 즉사
- 스프레이(우클릭/Q, 폰은 스프레이 버튼): 3회 + 리필 2회, 앞쪽 3m
- 1인칭 팔: 방역복 + 니트릴 장갑, 오른손 손전등, 왼손 살충제
- 손전등을 끄면 눈이 어둠에 적응해 가까운 곳이 희미하게 보임
- 손전등 과열: 오래 켜 두면 뜨거워지면서 빛이 어두워지고(누래지고 지직거림) 손전등 머리가 희미하게 달아오름. 한계를 넘으면 꺼져서 10초 동안 식힘(식는 동안 못 켜고 금속이 똑딱거림). 평소엔 끄고 있으면 천천히 식음. 화면의 배터리 표시는 없음
- 화면에 뜨는 말은 대부분 주인공의 혼잣말 ("손전등이 과열되었다", "손전등이 아직 뜨겁다", "소리를 듣고 오는 건가... 몸을 낮추고 걷자" 등)
- 효과음·환경음·추격 긴장음 (전부 코드로 합성): 다침, 부활, 리필, 떨쳐냄, 거미가 깨어남·움찔함, 바퀴 죽음, 알집 떨어짐, 손전등 지직거림·배터리 다 됨, 웅크릴 때 옷 소리, 탈출 등
- 입체 음향: 가까운 벌레는 한 마리씩 자기 발소리가 있어서 이어폰을 끼면 어느 쪽에 있는지 들림 (뒤에 있으면 소리가 먹먹해짐)
- 개발자 모드: 방/벌레 위치 순간이동, 무적·벽 통과·벌레 멈춤 등
- 벌레 모델: 바퀴벌레(날기 포함), 그리마형 지네, 늑대거미·유령거미

## 폴더 구조

```
src/            게임 코드
  map/          맵, 플레이어, 바퀴 떼
  roach.js      바퀴벌레 모델·애니메이션
  centipede.js  지네
  spider.js     거미
  silk.js       거미줄, 알집
  textures.js   절차적 텍스처
templates/      각 페이지의 HTML 틀
assets/         아이콘 원본 (SVG)
docs/           빌드 결과 + 앱 아이콘·manifest (GitHub Pages가 여기서 서비스)
build.mjs       src + templates → docs 로 묶는 스크립트
```

## 빌드

```
npm install
npm run build        # 모든 페이지
npm run build:map    # 게임 맵만
```

결과물은 `docs/` 에 하나짜리 HTML 파일로 나온다. 서버 없이 파일을 바로 열어도 동작한다.

## 1인칭 손 (게임에 적용됨, 따로 보기도 가능)

`docs/hands.html` · https://kimarthur815-collab.github.io/mandible/hands.html

- 파란 니트릴 장갑 + 흰 방역복 소매(손목 고무줄 주름) + 검은 전술 손전등, 전부 코드로 생성
- 손: 거리장(SDF)으로 만든 장갑 모양을 메시로 바꾸고 뼈 17개에 스키닝. 손가락이 쥔 물체에 닿을 때까지 감기는 방식으로 쥐는 모양을 계산
- 장갑 디테일: 펴진 손가락 마디엔 잔주름, 굽히면 손바닥 쪽 접힘, 손끝 미끄럼 방지 질감
- 게임에서 쓰는 포즈 4개: 기본 · 왼손 사용 · 손전등 끄기 · 스프레이
- 오른손은 레퍼런스 사진처럼 손등이 오른쪽을 보게 쥐고, 손목을 살짝 아래로 꺾어 손전등이 앞을 향함
- 게임 시점(어두운 방) / 스튜디오(돌려보기)
- 게임: 이 손을 그대로 사용 (오른손 손전등, 왼손은 늘 스프레이 캔, 뿌릴 때 캔을 들어 올림). 팔은 54° 화각의 별도 카메라로 그려 뷰어와 똑같이 보임
- 손전등 빛: 가운데가 밝고 가장자리가 부드러운 빛 무늬 + 빛줄기, 가까운 벽을 비추면 빛을 줄여 하얗게 타지 않음
